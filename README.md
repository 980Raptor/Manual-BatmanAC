A Manual Archipelago Integration for Batman Arkham City.

**What's randomized?**
- All Story Objectives
- All Side Missions
- Breakables (Tyger Cameras, Joker Balloons, etc.)
- All Riddler Trophies (optional)
- All Physical Challenges (optional)

**Items:**
- All Gadgets (Batarangs and Remote Batarangs are Progressive)
- All Level Up Upgrades
